# Прототип экранов

Макеты экранов этапа 1. Файлы `*.dc.html` — исходники прототипа для справки. Это не рабочий код и не компоненты: они рендерятся только в просмотрщике Claude Design (нужен его `support.js`), поэтому открывать их в браузере напрямую бесполезно. Используйте их, чтобы видеть состав полей, тексты, порядок блоков и демо-данные.

| Файл | Экран |
| --- | --- |
| Main.dc.html | Главная: показатели, «Требует внимания», ближайшие подачи, воронка, очереди |
| Clients.dc.html | Картотека: вкладки, фильтры, список и канбан по этапам |
| ClientCard.dc.html | Карточка клиента: кейс, очередь, сейф, брони, финансы в BYN, заметки |
| Analytics.dc.html | Аналитика: каналы, страны, результаты виз, визовые центры, очереди, месяцы |
| Styles.dc.html | Четыре варианта стиля интерфейса для выбора |

Палитра текущего прототипа (вариант A): синий #2453D6, тёмное меню #121A2B, фон #F4F5F8, шрифт Onest. Финальный стиль ещё не выбран — см. docs/open-questions.md.
