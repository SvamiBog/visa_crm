# Прототип экранов

Макеты экранов этапа 1. Файлы `*.dc.html` — исходники прототипа для справки. Это не рабочий код и не компоненты: они рендерятся только в просмотрщике Claude Design (нужен его `support.js`), поэтому открывать их в браузере напрямую бесполезно. Используйте их, чтобы видеть состав полей, тексты, порядок блоков и демо-данные.

| Файл | Экран |
| --- | --- |
| Main.dc.html | Главная: показатели, «Требует внимания», ближайшие подачи, воронка, очереди |
| Clients.dc.html | Картотека: вкладки, фильтры, список и канбан по этапам |
| ClientCard.dc.html | Карточка клиента: кейс, очередь, сейф, брони, финансы в BYN, заметки |
| Analytics.dc.html | Аналитика: каналы, страны, результаты виз, визовые центры, очереди, месяцы |
| Styles.dc.html | Четыре варианта стиля интерфейса для выбора |

## Макеты задач

Макеты экранов, которые рисует агент `screen-designer` до кода (docs/process.md). Файлы `<область>-<что>.html` открываются в браузере напрямую: они подключают стили самого приложения (`frontend/src/styles.css`) и его классы, показывают все состояния экрана, а проверяет их скилл `ui-audit` (`audit.cjs --file`). Утверждённый владельцем макет — образец, с которым агент `design-qa` сверяет готовый экран. Шрифты приложения в файле не грузятся, поэтому буквы в макете системные.

| Файл | Экран | Пункт бэклога |
| --- | --- | --- |
| clients-card-tabs.html | Карточка клиента по вкладкам: «Клиент», «Кейсы», «Паспорт и документы», «Поездки 90/180», «Сейф»; ряд вкладок с прокруткой на телефоне | 1.15.17 |
| clients-new-client.html | «Новый клиент» одним экраном: контакт, анкета, консультация, заметка; паспорт, согласие и договор свёрнуты | 1.15.16 |
